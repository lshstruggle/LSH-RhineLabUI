# 背景动画制作规范

> 用于「滚动驱动帧序列背景」的素材生产。产出物交给网页端做抽帧、分层加载与滚动映射。

## 一、成片硬性要求

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 镜头 | 一镜到底，零剪辑 | 任何 hard cut 在滚动时会变成硬跳 |
| 时长 | 8–12 秒（推荐 10 秒） | 太短滚动会过快，太长帧数超预算 |
| 分辨率 | 1920×1080 | 抽帧目标为 1280 / 960 宽 |
| 帧率 | 30 或 60 fps 源 | 抽帧时重采样为 12 fps |
| 编码 | H.264 高码率，或 ProRes | 避免源片已有压缩伪影 |
| 运动 | 匀速、平滑、无静止长段落 | 静止段落等于浪费帧 |
| 光影 | 全片统一曝光与色温 | 自动曝光漂移会导致滚动闪烁 |
| 后期 | 不加转场、不加变速、不加字幕水印 | 只需纯画面 |
| 构图 | 文字落位区低细节、高亮度、低对比 | 保证标题可读 |

## 二、生成方式建议

**优先「图生视频」，不要「文生视频」。**

1. 先用图像模型出一张定稿关键帧（构图、配色、光位都确定）。
2. 再以该图为起始帧，只描述相机运动，生成一段单镜头视频。

原因：文生视频在多镜头之间必然出现几何漂移与风格跳变，抽帧后滚动会出现"物体突然变形"；而图生视频锁定了首帧与视觉基调，全片一致性最好。

**相机运动推荐**（择一，不要混用）：

- 缓慢向前推进（dolly in）
- 缓慢上摇（crane up / tilt up）
- 轻微的横向环绕（orbit，角度不超过 ±25°）

避开：快速摇镜、变焦、手持抖动。

## 三、分镜与章节对应

5 章节 / 120 帧，每章节约 24 帧。

| 章节 | 帧区间 | 画面意图 | 文字落位 |
| --- | --- | --- | --- |
| 01 封面 | 000–023 | 由白场/浅色平面进入，主体尚未完全显现 | 中央或左半，留大片浅色平面 |
| 02 教育 | 024–047 | 镜头推进到第一个场景，结构感出现 | 左下，画面右侧保留结构 |
| 03 项目 | 048–071 | 进入核心场景，细节最丰富处 | 上/下留白，主体居中 |
| 04 技能 | 072–095 | 镜头转向或拉远，节奏放缓 | 右侧或整体留白 |
| 05 联系 | 096–119 | 收束到干净的终章构图，可循环回首帧 | 中央，画面尽量最简 |

要点：**第 1 帧是加载动画退场后第一眼看到的画面**，**第 120 帧是滚动到底的定格**，这两帧的构图优先级最高。

## 四、交付参数

```
1920x1080 / 30fps / H.264 (CRF 16-18) / yuv420p
或
1920x1080 / 30fps / ProRes 422
```

可选：同内容再出一版 **1080×1920 竖屏**母版，供移动端使用。若素材构图是中心对称或主体居中，可用横向版中心裁切替代。

## 五、抽帧命令参考

网页端会提供一键脚本，以下为等价命令，便于自行核对。

高清层（1280 宽 / 12 fps / WebP q72）：

```sh
ffmpeg -i background.mp4 \
  -vf "fps=12,scale=1280:-2:flags=lanczos" \
  -c:v libwebp -quality 72 -compression_level 6 \
  frames-hi/%04d.webp
```

低清首层（960 宽 / 12 fps / WebP q65）：

```sh
ffmpeg -i background.mp4 \
  -vf "fps=12,scale=960:-2:flags=lanczos" \
  -c:v libwebp -quality 65 -compression_level 6 \
  frames-lo/%04d.webp
```

校验帧数：

```sh
ls frames-hi | wc -l
```

期望值：时长的秒数 × 12。10 秒素材应为 120 帧（编号 0001–0120）。

## 六、体积预算

| 方案 | 帧数 | 单帧 | 合计 |
| --- | --- | --- | --- |
| 30 fps · 1920 宽 · JPEG | 300 | ~220 KB | ~66 MB |
| 30 fps · 1280 宽 · JPEG | 300 | ~110 KB | ~33 MB |
| 12 fps · 1280 宽 · WebP（高清层） | 120 | ~55 KB | ~7 MB |
| 12 fps · 960 宽 · WebP（低清首层） | 120 | ~20 KB | ~2.4 MB |

采用两层策略：低清首层先到（首屏可用），高清层后台静默替换。

## 七、验收清单

- [ ] 全片无剪辑切点
- [ ] 首帧与末帧构图满足文字落位
- [ ] 全片无曝光/色温突变
- [ ] 无静止超过 0.5 秒的段落
- [ ] 抽帧后帧数 = 时长 × 12
- [ ] 逐帧快速拖动检查：无重影、无跳变、无压缩块
